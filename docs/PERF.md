# 避让查询优化：成本分解、计算顺序与失效规则

本文档说明连续帧字幕避让中"重复求人物区域与候选位置"的成本如何测量、
避让查询优化按什么顺序复用仍然有效的几何信息，以及什么时候必须让旧候选
立即失效。运行基准：`python3 scripts/perf_avoidance.py`
（报告写入 `data/perf/avoidance-report.json`，即遮挡比例与布局耗时的执行证据）。

## 成本分解（AvoidanceStats）

`evaluate_timeline(..., stats=AvoidanceStats())` 会记录每个查询阶段的
调用次数、缓存命中、耗时与工作量单元：

| 阶段 | 含义 | 工作量单元 |
| --- | --- | --- |
| `regionQuery` | 求某时间区间内的活动人物/手语/重要区域集 | 扫描的区域数 |
| `positions` | 生成安全区内的候选位置网格（锚点+网格+去重） | 生成的点数 |
| `conflicts` | 候选框与区域求交（硬约束检查） | 框×区域对数 |
| `wrap` / `measure` | 真实字形换行与墨迹度量 | 字符数 |
| `occupancy` | 区域对安全区的占用率采样 | 采样格数 |

每条字幕另记录：**布局耗时**（`cueLayoutSeconds`）、**遮挡比例**
（`occupancyRatio`，活动区域对安全区的占用率）、**检查区间数**
（`intervalsChecked`，检查帧密度的直接证据）。

## 避让查询优化的计算顺序

1. **逐条字幕评估**（`evaluate_timeline`）：每条字幕开始时校验区域签名
   （`AvoidanceOptimizer.fresh`）。签名由全部区域的 id/类型/时间范围/矩形
   构成——快速手势、区域跳变都会改变签名，旧候选**立即失效**（缓存整体清空）。
2. **整段尝试**：先对整条字幕求活动区域并集（按 `(start,end)` 缓存），
   能一次放稳则不拆分。
3. **断点切分**：整段不可解时按区域起止时间切分区间，逐区间求解。
   断点数量与求解区间数不因优化减少——0.24s 的短暂全遮挡仍被单独求解并
   显式标为未解，不会被合并或跳过。
4. **区间内**（`_solve_static`）：字号×宽度变体 → 换行（按文本/字号/宽度
   缓存）→ 墨迹度量（按行内容/字号缓存）→ 候选位置网格（按安全区/块尺寸/
   步长缓存，去重是 O(n²)，是最大的重复成本）→ 安全区过滤 → 冲突检查
   （区域 Rect 每次求解只计算一次；框×区域集的结果按缓存键复用）→ 评分 →
   稳定性保持（沿用上一条/已采用位置的逻辑不变）。
5. **失效即重算**：所有缓存键包含计算的全部几何输入，命中即"仍然有效"；
   输入一变键就变，旧值自然不再命中。优化只省重复计算，不改变任何输出。

## 回归闸门

`backend/tests/test_perf.py` 固定以下不变量；任一失败即视为优化退化，
应撤回相应优化：

- 优化路径与运行参照（`evaluate_timeline_reference`，未优化路径）的输出
  逐字段一致——除遮挡比例与布局耗时外不允许任何行为差异；
- 渲染分段连续覆盖整条字幕、区间数等于断点推导值（检查帧数不减少）；
- 遮挡比例与布局耗时来自真实测量（非 0、非缺失、两路径一致），
  不得以默认值遮错；
- 速度比较只在避让查询优化完整执行后进行：先参照、后优化、再比较，
  优化后总布局耗时必须下降。

## 当前场景基线

快速手势（0.15s 跳变的手语动作区 × 80）+ 移动人物保护区（0.5s 时间片）+
窄安全区（88px）+ 0.24s 全画面短暂遮挡 + 9 条连续字幕。基线结果（见
`data/perf/avoidance-report.json`）：候选网格点数约 22.2 万 → 2.8 万，
冲突检查对数约 122 万 → 46 万，总布局耗时约 3.8s → 1.6s（约 2.4x），
输出完全一致。
